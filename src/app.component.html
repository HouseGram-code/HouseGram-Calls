1. Общие положения

HouseGram Calls предоставляет технологию для связи P2P (Peer-to-Peer). Мы не являемся оператором связи.

2. Запрещенный контент

Запрещено использование сервиса для совершения противоправных действий, терроризма, экстремизма или распространения запрещенной информации согласно законодательству РФ.

3. Ответственность

Пользователи несут полную личную ответственность за содержание своих разговоров. Администрация не осуществляет модерацию голосового трафика, так как он зашифрован и передается напрямую между устройствами.

} @if (activeModal() === 'policy') {

1. Сбор данных: Приложение HouseGram Calls не записывает и не хранит аудиозвонки на серверах. Весь голосовой трафик передается напрямую между пользователями (WebRTC).

2. Метаданные: Для соединения устройств мы используем временные идентификаторы (SDP, ICE Candidates), которые удаляются после завершения сессии.

3. Третьи лица: Данные не передаются третьим лицам, за исключением случаев, предусмотренных законом.

4. Безопасность: Соединение защищено шифрованием DTLS/SRTP (стандарт WebRTC).
